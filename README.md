A fast, dependency-free Markdown renderer (CommonMark 0.31.2 + GFM 0.29) that produces byte-identical output to marked 18.1.3 with default settings. Single-pass line-based block parser and delimiter-stack inline parser, written for speed.

## Run it

```sh
node --experimental-strip-types main.ts
```
